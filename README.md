# ⚡ Svet — бот отключений света (Одесса, ДТЕК)

Telegram-бот: следит за графиками и авариями ДТЕК Одеські електромережі по адресам пользователя и предупреждает заранее.

## Что умеет
- ➕ Несколько адресов: улица текстом (рус/укр) или 📍 геопозиция → дом → очередь определяется сама
- 📊 График (вариант B2): есть ли свет сейчас и когда выключат/включат + интервалы без света на сегодня/завтра
- ⚠️ Предупреждение до отключения (30 и/или 10 мин), 💡 до включения (30 и/или 10 мин)
- 🚨 Аварийные/текущие отключения по дому, 📅 изменения графика и новый график на завтра
- 🌙 Тихие часы (с какого по какой час не присылать)

## Устройство
- Cloudflare Worker `svet`, D1 `svet` (binding `DB`), cron каждые 5 минут
- Данные: страница `dtek-oem.com.ua/ua/shutdowns` (`DisconSchedule.fact`, `DisconSchedule.streets`) и AJAX `getHomeNum` (дома улицы, очередь, текущее отключение). Сайт запрашивается не чаще раза в ~10 минут.
- Геопозиция → адрес: OpenStreetMap Nominatim

| Файл | Что внутри |
|---|---|
| `src/index.js` | Роуты: `/webhook`, `/setup`, `/run`, статус; cron |
| `src/bot.js` | Меню, добавление адресов, график, настройки |
| `src/cron.js` | Обновление данных, изменения графика, аварии, предупреждения |
| `src/dtek.js` | Запросы к сайту ДТЕК |
| `src/schedule.js` | Слоты, полоска, интервалы, события, время Киева |
| `src/fuzzy.js` | Нечёткий поиск улиц/городов |
| `src/render.js` | Текст графика |
| `src/db.js` | Схема D1 и запросы |
| `src/tg.js` | Telegram API, клавиатуры |

## Настройка
1. Секрет `BOT_TOKEN` (токен от @BotFather) в настройках воркера.
2. Открыть `https://svet.iladislaus-gold-3ef.workers.dev/setup` — ставит вебхук и команды.

Бот неофициальный, не связан с ДТЕК.
